# Portfolio de proyectos de IA

Soy Unai. En estos proyectos muestro cómo uso herramientas de IA para diseñar webs y convertir datos en recomendaciones. Los tres casos son ejercicios con marcas, situaciones o datos ficticios.

| Proyecto | Qué puedes ver | Por dónde empezar |
| --- | --- | --- |
| **Linde & Arce Abogados** · ChatGPT Sites | Una web que guía a quien tiene una duda legal desde su situación hasta el área correspondiente y el formulario de prueba. | [Ver el vídeo de 2:43](https://unai-598.github.io/portfolio-linde-arce-abogados/) · [Leer el caso](https://github.com/unai-598/portfolio-linde-arce-abogados) |
| **Evaluación de proveedores** · ChatGPT Work | Un análisis de 600 pedidos que sirve de base para proponer la renegociación con cuatro proveedores y estudiar alternativas para uno. | [Ver el resumen y los entregables](https://unai-598.github.io/portfolio-ia-compras-proveedores/) · [Leer el caso](https://github.com/unai-598/portfolio-ia-compras-proveedores) |
| **Velora Chairs** · Lovable | Una tienda de prueba con diez modelos de sillas, filtros para comparar opciones y un carrito de demostración. | [Probar la demo](https://velora-chairs.lovable.app/) · [Leer el caso](https://github.com/unai-598/portfolio-velora-chairs) |
